BeamLab — прототип физики мягких тел в стиле Rigs of Rods / BeamNG
====================================================================

Машины и объекты состоят из узлов и балок: они мнутся, рвутся и ломаются.
Машины — оригинальные моды Rigs of Rods (22 модели, 70 вариантов).

Требования
----------
- macOS 11 или новее, любой Mac на Apple Silicon (M1 и новее) или на Intel.
- Около 2 ГБ свободного места после распаковки.

Первый запуск
-------------
Приложение не подписано сертификатом Apple, поэтому при первом запуске
macOS скажет, что не может проверить разработчика. Как открыть:

  1. Двойной щелчок по BeamLab.app. Когда появится предупреждение, нажмите «Готово».
  2. Откройте «Системные настройки» → «Конфиденциальность и безопасность»,
     прокрутите вниз и нажмите «Всё равно открыть» рядом с BeamLab.
  3. Снова запустите BeamLab.app и подтвердите «Открыть».

Или одной командой в Терминале (путь поправьте под свою папку):

  xattr -dr com.apple.quarantine ~/Downloads/BeamLab/BeamLab.app

Управление
----------
  W / S, A / D         газ / тормоз (задний ход: держать S на месте), руль
  Space                ручник
  R / Shift+R          поставить машину на колёса / вернуть на старт
  C / F                режим камеры / свободная камера (WASD, Q/E, Shift — быстрее)
  Tab                  пересесть в следующую машину сцены
  Правая кнопка мыши   вращать камеру, колесо — зум
  G / X / B            инструмент: тянуть узлы / разрушать (держать ЛКМ) / стрелять (ЛКМ)
  Z, «,» / «.»         тип снаряда, скорость снаряда
  [ / ]                замедлить / ускорить время, T — слоумо, Backspace — 1x
  P / N                пауза / шаг
  F5                   перезапустить сцену
  F1                   полная справка, F2 — окно производительности

Мир и машина выбираются в выпадающих списках в верхнем меню.
Интересные сцены:
- Physics Lab — листы ткани, стали и пластика для стрельбы;
- Canyon Bridges — мосты, которые ломаются под тяжёлыми машинами;
- Vehicle vs Vehicle — столкновение двух машин, настраивается в меню Scene.

Авторы машин
------------
Моды взяты из официального репозитория Rigs of Rods (forum.rigsofrods.org).
Авторы и ссылки лежат в файле SOURCE.txt в папке каждой машины:
BeamLab.app/Contents/Resources/assets/vehicles/<машина>/SOURCE.txt

--------------------------------------------------------------------
English, in short: macOS 11+, Apple Silicon or Intel. The app is not signed,
so on first launch open System Settings → Privacy & Security → "Open Anyway",
or run: xattr -dr com.apple.quarantine /path/to/BeamLab.app
Controls: WASD drive, C/F camera, G/X/B tools (grab / destroy / shoot), F1 help.
